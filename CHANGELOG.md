# Changelog

All notable changes to MTDirector (MikroTik Firewall Controller) are documented in this file.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Security

- Pin transitive `SSH.NET` to 2026.0.0 (CPM) so NuGet audit no longer fails restore on GHSA-q939-rpr3-3284 from Testcontainers 4.13.

### Fixed

- TCP flag intersection: identical `required_present`/`required_absent` is a set-union, not a duplicate-throw empty cube, so exception overlap stays fail-closed.
- Exception-path service JSON: missing port bounds or a non-array ports/ICMP field maps to `POLICY_COMPOSE_SELECTOR_UNRESOLVED` instead of throwing or treating the field as unconstrained.
- Desktop inventory cancel race: await shared refresh before surfacing cancellation so `IsRefreshing` clears consistently.
- Unit tests: explicit non-UTC offsets; zone/snapshot/policy coverage to meet Domain/Application CI thresholds.

### Changed

- ROADMAP: M2-16 closed in the operating plan; NEXT = M2-17 (#64); counters 65/109 MVP done (44 remaining).

### Added

- Policy tests, semantic diff, and risk classification (M2-16): Domain `PolicyEvidenceAnalysis` evaluates MANAGED_ONLY and NODE_EFFECTIVE `PolicyTestCase` packets, UUID-keyed revision diff (ADDED/REMOVED/MODIFIED/MOVED/ENABLED/DISABLED) with object impact and newly accepted/denied packet spaces, and a max-of-drivers risk floor (comment-only LOW; add-deny/remove-allow MEDIUM; add-allow/remove-deny/FastTrack/exception HIGH; management/default/zone-binding/unknown CRITICAL). SYSTEM tests cannot be disabled; failed/INDETERMINATE safety tests are BLOCKERs. Evidence context hash (`mfc.policy.evidence_context.v1`) enters analysis context without changing the M2-12…M2-15 combiners. Application canonical mapper + RouterOs discovery mapper. Safety BLOCKERs → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged; `PolicyDocument.Tests` stays opaque JSON; tests are evaluated, not generated.
- FastTrack policy validation (M2-15): Domain `FastTrackAnalysis` allows `FASTTRACK_ACCEPT` only on proven-safe IPv4 FORWARD company STATE_PRELUDE with TCP/UDP and ESTABLISHED,RELATED; fail-closes on IPv6/INPUT/OUTPUT, unconstrained protocol, PCC, balanced/mixed/unknown WAN, routing marks, non-main tables, IPsec, VRF, unknown Mangle, packet marks after FastTrack, missing conntrack/HotSpot/queue-tree, logging, and unmanaged pre-anchor FastTrack (`PRE_ANCHOR_FASTTRACK_BYPASSES_POLICY`). Compiler ACCEPT fallback is a mandatory result flag (`RequiresAcceptFallback` / `FASTTRACK_FALLBACK_REQUIRED` WARNING), not a RouterOS write. Risk floor stays HIGH whenever FastTrack is present. FastTrack context hash (`mfc.policy.fasttrack_context.v1`) enters analysis context without changing the M2-12/N1-04/M2-13/M2-14 combiners. Application canonical mapper + RouterOs discovery mapper (pre-anchor scan + VRF nodes; `ipv4-fasttrack-active` observation-only). FastTrack BLOCKERs → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged; FastTrack/ACCEPT pair is never compiled or written.
- Topology and dependency safety validation (M2-14): Domain `TopologyDependencyAnalysis` generates VRRP protocol-112 advertisement flows (IPv4 `224.0.0.18` / IPv6 `ff02::12`) and UDP conntrack-sync flows (default 8275); fail-closes on `VRRP_MEMBER_MISSING`, unbound uplink zones, `STRICT_RPF_*` with VRRP/tables/asymmetry, RAW notrack intersection / unhandled UNTRACKED / unknown RAW matchers, NAT unknown matchers, and SWITCH FORWARD / unknown chip / unproven transit. PCC and routing marks are WARNING (`MANGLE_PCC_PRESENT` / `MANGLE_ROUTING_MARK_PRESENT`); DSTNAT without NAT evidence is WARNING. Split-master role vector is preserved (never a collapsed global master). Topology context hash (`mfc.policy.topology_dependency_context.v1`) enters analysis context without changing the M2-12/N1-04/M2-13 combiners; VRRP role and active default routes stay in the observation hash only. Application canonical mapper + RouterOs discovery mapper (typed VRRP sync fields; RAW/NAT/Mangle extras projected). Topology BLOCKERs → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged; NAT/RAW/Mangle/VRRP are never written; primary WAN is never disabled.
- Management-path safety validation (M2-13): Domain `ManagementPathAnalysis` fail-closes reconnect when API-SSL is missing/disabled/port-mismatched, controller sources are outside the IP-service allowlist, the pre-anchor guard is missing/moved/invalid, TCP NEW or ESTABLISHED reply is not proven, an unmanaged pre-anchor DROP/REJECT sits on the path, or the candidate would rewrite the guard. VRRP VIP-only and DNS destinations are `MANAGEMENT_PATH_INDETERMINATE`. SYSTEM tests (INPUT NEW / OUTPUT ESTABLISHED) and witness packets are generated when the destination is a concrete IP. Management context hash (`mfc.policy.management_path_context.v1`) enters analysis context without changing the M2-12 one-argument or N1-04 two-argument preimages. Application canonical mapper + RouterOs discovery mapper (`api-ssl.address` now projected). `MANAGEMENT_*` → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged; guards are never auto-created.
- Packet-path analysis blockers (N1-04): Domain `PacketPathAnalysis` emits BLOCKERs `PACKET_PATH_BYPASSES_IP_FIREWALL` (HARDWARE_OFFLOADED_PATH) and `PACKET_PATH_NOT_PROVEN` (INDETERMINATE) for managed FORWARD; MIXED/CPU do not emit those codes. Packet-path context hash (`mfc.policy.packet_path_context.v1`) enters analysis context without changing the M2-12 one-argument preimage. Application canonical mapper + RouterOs classification mapper. Controller never disables L2/L3 offload. `PACKET_PATH_*` → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged; live N1-05 projector residual untouched.
- Actual RouterOS filter-context analysis (M2-12): Domain `ActualFilterAnalysis` builds a bounded filter CFG (jump/return/cycle, depth 16, 50 000 nodes, 1024 chains); unmanaged pre-anchor ACCEPT/DROP/REJECT/FastTrack/dynamic/indeterminate are BLOCKERs; post-anchor is walked only for `RETURN_TO_UNMANAGED`; RouterOS implicit accept is never the managed default. Actual context hash (`mfc.policy.actual_filter_context.v1`) enters analysis context. Application canonical mapper + RouterOs discovery mapper (dynamic rows + unknown matchers). `ACTUAL_FILTER_*` / `PRE_ANCHOR_*` → FailedPrecondition `retryable=false`. Desktop OUT; no new RPC; compose unchanged.
- Duplicate / shadow / overlap analysis (M2-11): Domain `PolicySequenceAnalysis` on pipeline-ordered enabled rules after M2-10; exact duplicates stay in the active list (WARNING); conflicting duplicates, full shadows, split-cover indeterminate, earlier-allow-bypasses-deny, and FASTTRACK-vs-deny are compose BLOCKERs with witness packets. `SHADOW_ANALYSIS_INDETERMINATE` / `EARLIER_ALLOW_BYPASSES_DENY` / `FASTTRACK_OVERLAP` → FailedPrecondition `retryable=false`.
